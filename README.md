# NLDB
A highly flexible, multi-user database/inventory management software built on a modern, desktop & mobile friendly web platform (HTML5 & Node.js w/ MongoDB). Enables tracking taggable tools & assets, parts, consumables, and just about anything else! It features *(or will feature)* an interactive editor, QR code generator, mobile device QR scanner, custom fields, rulesets, search, granular user permissions, and history/audit logging.
